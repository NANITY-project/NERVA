# Data credits

NERVA's motion grader and its motion models (the cVQ-VAE and its prior) rely on third-party motion-capture data. This file credits each source, states its licence, and says how the data is used. The grader's reference ranges and the trained model weights are derived from the data listed below, so this notice must stay with them if they are redistributed.

None of the original motion-capture files are included in this repository. The example clips in `include/motion/` are short converted excerpts of 100STYLE and ACCAD / Ohio State University data, redistributed under the licences below (see "Example clips" at the end); no CMU clips are included in any form.

## CMU Graphics Lab Motion Capture Database

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

- Source: http://mocap.cs.cmu.edu/
- BVH conversion by B. Hahne (cgspeed), mirrored at https://github.com/sfd158/cmu-mocap
- Terms: CMU states the data is free to use and may not be resold directly, even in converted form. The maintainers confirmed by email that the uses below are permitted.

How it is used:

- The grader's reference ranges (typical and tolerable ranges of body measurements per action, in `include/motion/nerva_motion_profiles.hpp`) are computed from a portion of the database.
- The grader scores motions generated by the NERVA engine. CMU clips are used locally for this and are not redistributed.
- Model training uses motion generated by the engine and filtered by the grader. CMU clips are not part of the training set.

## 100STYLE

Mason, Ian; Starke, Sebastian; Komura, Taku. *100STYLE Dataset.* Zenodo, 2022. https://zenodo.org/records/8127870

- Paper: "Real-Time Style Modelling of Human Locomotion via Feature-Wise Transformations and Local Motion Phases", https://arxiv.org/abs/2201.04439 (DOI 10.1145/3522618)
- Licence: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/

How it is used:

- Grader reference: part of the data is used to compute a separate style profile in the grader's reference ranges (`style_walk`, `style_run`, `style_idle`).
- Model training: part of the data is used to train the VAE and prior.

Changes made: BVH files were retargeted and scaled to the NERVA skeleton, converted to NERVA's 30-channel action vector, cut into fixed-length windows, and extended with graded variants (for example mirrored and time-warped copies). The grader's reference ranges and the trained models are derived from this processed data.

## ACCAD / Ohio State University motion capture data

Open Motion Project by ACCAD / The Ohio State University, https://accad.osu.edu/research/motion-lab/system-data

- Licence: Creative Commons Attribution 3.0 Unported, https://creativecommons.org/licenses/by/3.0/

How it is used:

- Grader reference: part of the data is used to compute the grader's reference ranges.
- Model training: part of the data is used to train the VAE and prior.

Changes made: the same processing as for 100STYLE above (retargeting, conversion to the 30-channel action vector, windowing, graded variants). The grader's reference ranges and the trained models are derived from this processed data.

## Example clips in `include/motion/`

`include/motion/nerva_motion_<action>.hpp` hold a few short example clips per action, written by `tools/export_headers.py` from the 100STYLE and ACCAD / Ohio State University data above and from nothing else. Each header repeats the credit and licence. Changes made beyond those listed above: clips are at most a few seconds long, resampled to 15 fps and quantised to 16-bit integers. These headers are a derived work of those datasets and carry the same attribution requirement.
