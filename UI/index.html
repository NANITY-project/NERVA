How it works

The stage
Red limbs · ivory limbs
Left side is red, right side is ivory.
Green disc
A planted foot.
Pink dot
Centre of mass, with a dashed line down to the floor.
Dark red trail
Where the pelvis has been.
Red frame around the stage

The codes
Card
One window of motion. Open Codes at the bottom to see them.
Cell
One VAE code the prior just sampled. Brighter means more confident. Hover for the code, probability and entropy.
Glowing cell
The code being sampled right now.
Uncertainty line
Prior entropy per code, in nats. Higher means the model is less sure.
Card footer
Time spent on that window. Hover for the prior, NEON and engine split.
Sampling
Action
What kind of motion to ask for, or none.
Temp
Lower is safer and repetitive. Higher is looser and stranger.
Top-k
Only the k likeliest codes are considered. 0 turns it off.
Top-p
Only the smallest set of codes adding up to p is considered.
Seed
Same seed and settings give the same motion.
Windows · Endless
How many windows to generate, or keep going until you stop.
Status
Lit dot
NEON backend, body engine, VAE and prior are loaded.
Amber dot
Body engine failed to load. A preview skeleton is drawn from the action channels instead.
